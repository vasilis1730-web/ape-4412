## Προσοχή πριν την εισαγωγή στην εφαρμογή

Το `.xlsx` περνά ολόκληρο τον έλεγχο εισαγωγής της εφαρμογής, με μία εξαίρεση
που **δεν οφείλεται σε αυτό το αρχείο** αλλά σε σφάλμα της ίδιας της εφαρμογής:

1. **`material_id` (μπλοκάρει την εισαγωγή).** Στο `index.html` του
   `promitheies-rodou-staging` ο έλεγχος του φύλλου `ΚΛΕΙΔΙΑ_ΕΙΔΩΝ` δέχεται
   μόνο αριθμητικά αναγνωριστικά (`/^\d{1,20}$/`), ενώ η εφαρμογή εξάγει UUID.
   Έτσι **κανένα** export δεν μπορεί να επανεισαχθεί. Διόρθωση:

   ```js
   // πριν
   if(!/^\d{1,6}$/.test(ordinalText)||!/^\d{1,20}$/.test(materialId)||groupId!==String(cur.groupId)){
   // μετά
   const idOk=/^(?:\d{1,20}|[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12})$/i.test(materialId);
   if(!/^\d{1,6}$/.test(ordinalText)||!idOk||groupId!==String(cur.groupId)){
   ```

2. **Συγχωνευμένες γραμμές ενότητας.** Το export γράφει τους τίτλους
   υποκατηγοριών ως merged κελιά `A:L`. Κατά την ανάγνωση το κείμενο
   «χύνεται» σε όλες τις στήλες, οπότε πέφτει στον έλεγχο του Α/Α και του CE.
   Το παρόν αρχείο **δεν** χρησιμοποιεί merge: οι τίτλοι μπαίνουν μόνο στη
   στήλη ΠΕΡΙΓΡΑΦΗ και ξεκινούν με «ΟΜΑΔΑ », ώστε η εισαγωγή να τους προσπερνά.

Η εισαγωγή απαιτεί λογαριασμό **administrator** (μόνο αυτός ενημερώνει
περιγραφές, τιμές και προδιαγραφές του κεντρικού καταλόγου) και ισχύον
`EXPORT_TOKEN` — το ενσωματωμένο λήγει στις **03/09/2026**.
